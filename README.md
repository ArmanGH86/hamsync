# HamSync

**Watch together, each on your own device.** Everyone plays their own copy — YouTube or any website, a downloaded
file, VLC — and HamSync keeps play, pause and the exact time identical for the whole group. Nothing is streamed.

**با هم تماشا کنید، هرکس روی دستگاه خودش.** هرکس نسخه‌ی خودش را پخش می‌کند و هم‌سینک پخش، توقف و زمان را برای همه یکسان نگه می‌دارد.

## In short

1. One person creates a room and shares the 6‑letter code.
2. Everyone else joins with the code.
3. Each person opens the same film or song in whatever they like. HamSync recognises it by its length
   (file names don't matter) and keeps everybody on the room creator's time. If anyone pauses, it pauses for all.

## راهنمای سریع (فارسی)

1. هم‌سینک را نصب کنید: **افزونه** برای تماشا در مرورگر، **برنامه** برای فایل دانلودشده (رایانه یا گوشی).
2. حساب بسازید (نام کاربری و رمز).
3. یک نفر **ساخت اتاق** را می‌زند و کد ۶ حرفی را برای بقیه می‌فرستد؛ بقیه با **ورود به اتاق** وارد می‌شوند.
4. میزبان فیلم یا آهنگ را شروع می‌کند؛ بقیه همان را به روش خودشان باز می‌کنند (سایت، فایل، VLC). اسم فایل مهم نیست — از روی طول زمان شناخته می‌شود.
5. هرکس توقف، پخش یا جابه‌جا کند، برای همه اعمال می‌شود. با کلید **همگام‌سازی** می‌توانید موقتاً مستقل شوید.
